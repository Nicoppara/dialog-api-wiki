# DialogAPI Maven 仓库

把下面的仓库地址加入项目，Maven 或 Gradle 就能按坐标自动下载 DialogAPI。

```text
https://nicoppara.github.io/dialog-api-wiki/maven/
```

添加 `https://repo.momirealms.net/releases/` 解析传递依赖 `net.momirealms:sparrow-nbt:0.26`。完整配置已包含两个仓库。

[复制 Maven、Gradle Groovy 或 Kotlin DSL 配置](https://nicoppara.github.io/dialog-api-wiki/installation/)
